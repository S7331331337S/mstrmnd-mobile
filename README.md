# MSTRMND Mobile

The MSTRMND Agent Alliance, in your pocket. A React Native + Expo client for conversing with the personal intelligence layer.

Standalone repo extracted from [mstrmnd-core](https://github.com/S7331331337S/mstrmnd-core) (`apps/mobile`).

```bash
pnpm install
pnpm dev
```

Press `w` for web. Chat works with no API key (demo model). See the rest of this README after the full tree is pushed.
